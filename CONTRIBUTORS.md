entry links to the contributor's GitHub profile. The format
is inspired by the [All Contributors](https://allcontributors.org)
specification but kept minimal — a list of names, not a
per-contribution emoji rollup.

## How to be added

When your first PR merges, the maintainer will add a row
to the **External contributors** table in the same release
that includes your contribution. The PR template asks
whether you want to be credited; the default is "yes, with
my GitHub handle as the link".

If you prefer a different name (your real name, your
organization, or "anonymous"), say so in the PR.
