What a self-hostable kanban should be

A complete project-management surface with no hosting padlock, and AI as a first-class citizen.

Boards built for work

Workspaces, boards, lists, cards, members, comments, checklists and attachments.

First-class MCP server

A peer of the REST API: same domain, same authorization, same idempotency. Your AI client moves cards the way a person would.

Calendar and planner

Due dates, a monthly view, a list-based planner, recurring cards and notices in your inbox.

Automation

Server-side rules: when a card is completed, move it; when a new one arrives, assign it. A failed rule never blocks the user.

Multi-database

SQLite for solo use, PostgreSQL, MySQL or MariaDB for production. The provider is configuration, not code.

Integrations

Slack, GitHub, email-to-board, Google Calendar, SCIM provisioning and SAML SSO, plus webhooks and API tokens.

Security and audit

Per-workspace roles, TOTP 2FA, an audit log, rate-limited tokens and your own signing keys.

Per-board extensions

Custom fields, voting, card repeater and card aging, switched on board by board.

Modern end to end

ASP.NET Core 10, Blazor WebAssembly, Entity Framework Core and Radzen. English and Spanish UI with light and dark themes.

Tour

Built for the everyday

A board that feels fast

Lists, labels, members, due dates and checklists at a glance. Open a card to see its description, progress and actions.

  • Checklists with progress and comments with mentions
  • Move, copy, mirror and complete in one click
  • Board metrics with configurable charts

Deadlines under control

The calendar shows what is due each day, and the inbox alerts you about overdue work, upcoming deadlines and mentions.

  • Calendar view and list-based planner
  • Due-date and assignment notices
  • Optional Google Calendar sync

Rules that work for you

Define what happens when a card changes. Rules run on the server and never interrupt the person who made the change.

When

A card is completed, created in a specific list or moved to another list.

Then

Move the card, assign someone or add a label.

Your AI, your rules

The MCP server uses the same application layer as the web UI. Create a read-only or read-write API token and connect your AI client.

  • Per-client tokens, rate-limited and revocable
  • The same authorization and validation as the web
  • Every action lands in the activity log

Teams and administration

Invite people to a workspace, assign roles and review the audit log. Connect your tools from a single panel.

Your look, your colors

Six themes, light, dark or system mode, and a live preview. The preference follows your account.

Install

Your server in a minute

Cardscape is a server application: it installs nothing on your computer. Run it with Docker Compose or the .NET SDK.

docker compose
$ git clone https://github.com/FittyAr/Cardscape.git && cd Cardscape echo "CARDS_CAPE_JWT_KEY=$(openssl rand -base64 48)" > .env docker compose up -d
# Open http://localhost:7420 and follow the setup wizard
$ git clone https://github.com/FittyAr/Cardscape.git && cd Cardscape dotnet run --project src/Cardscape.Api
# API and Blazor client at http://localhost:5291
Server data With Docker it lives in named volumes: cardscape.data, cardscape.uploads, cardscape.keys and cardscape.postgres_data.
Local tools If you run Cardscape without Docker, user config and data go to %APPDATA%\FittyAr\Cardscape.
Local install An installed app on Windows would go to %LOCALAPPDATA%\Programs\FittyAr\Cardscape.
