## How to add an entry

When a confirmed vulnerability is
disclosed, the maintainer adds an
entry to the table below with the
reporter's preferred name (or
"anonymous" if the reporter prefers),
the date, the advisory link, and a
one-line summary of the impact.

## Recognition levels

The maintainer recognises reporters
in three ways, in increasing order of
impact:

1. **Name in this file** — every
   confirmed report.
2. **Name in the release notes** —
   reports of severity High or
   Critical.
3. **T-shirt / sticker pack** — for
   reports of severity Critical that
   required a coordinated disclosure.
   (The maintainer ships swag only
   if/when the budget supports it.
   This is a soft commitment, not a
   paid bounty.)

## Anonymity

Reporters can request anonymity at
any time. The maintainer will:

- omit the reporter's name from the
  advisory
- omit the reporter's name from
  this file
- omit the reporter's name from the
  release notes
- continue to credit the reporter
  in the maintainer's private
  records (for the maintainer's
  own future reference)

Reporters can also request a
**partial credit** (e.g. first name
only, GitHub handle only, etc.).
